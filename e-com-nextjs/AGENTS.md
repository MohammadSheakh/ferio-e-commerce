# Ferio Workspace Guidance

This directory contains the backend and all Ferio clients.

- Read the root [Codex project context](../.codex/PROJECT_CONTEXT.md) first.
- Read the applicable `.codex` context file before editing backend, frontend, or operations code.
- Read the nearest child `AGENTS.md`; it overrides this general workspace guidance for that app.
- Treat the PRD, implementation checklist, ADRs, and existing skills as canonical references rather than copying them into new files.
- Keep platform admin, tenant admin, customer, mobile, and backend responsibilities separate.
- Do not change API contracts, tenant boundaries, or shared design language casually.
